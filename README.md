# ACTA · 纯后端角色卡工厂与剧情引擎

> 交换与协作仓库。**本仓库为公开仓库，任何提交都会对外可见** —— 提交前请对照文末"禁止提交清单"。

## 这是什么

一个纯后端服务：**角色卡工厂 + 剧情生成引擎**。

三条入口，一个引擎：

```
① 新建   提交规格 → 生成合规卡包
② 导入   上传现有第三方客户端卡 → 解析、归一化、重新出包
③ 游玩   同一引擎承接剧情生成（OpenAI 兼容接口）
```

## 目录

```
docs/
  规格-v3-答复与增量.md     当前生效规格（含对评审回执的逐条答复）★以本文为准
  假宿主接口契约.md         进程契约 + 产物判据 + 失败分类
mock/
  fake-host.mjs            零依赖假宿主（ok / empty / refuse / slow / dirty 五模式）
acceptance/
  用例清单.md              验收用例与批次（样本不公开，见文末）
```

## 协作约定

1. **规格以 `docs/规格-v3-答复与增量.md` 为准**；更早版本作废。
2. 变更走 **PR**，一次 PR 一件事；PR 描述里写：改了什么、怎么验的、影响哪些用例编号。
3. 每个里程碑交付时附：单测输出、验收脚本的输入样本（脱敏）与输出矩阵、已知限制清单。
4. 需要联调时用 `mock/fake-host.mjs` 或本地假供应商，**不消耗真实额度、不使用真实凭据**。
5. 有疑问先在 Issue 里问，不要靠猜实现。

## 里程碑

| # | 交付 | 验收要点 |
|---|---|---|
| M0 | 加固：鉴权 / 健康探针收敛 / 错误不回原文 / 日志 JSON + 轮转 / 输出闸门记录 | 用例 M0-01…04 |
| M1a | 建卡接口 | 五段齐全、硬边界全过、导出卡可被目标客户端导入 |
| M1b | 导入接口 | 5 张形态各异样本全过、**round-trip 一致**、差异报告可读 |
| M2 | 直连与宿主并存 A/B | 10 对固定输入，出差异报告 |
| M3 | 切换与服务器化 | 延迟/内存/成功率按固定口径报告 |

## 禁止提交清单

**以下内容一律不得进入本仓库（含 issue、PR 描述、截图）：**

- 任何 API 密钥、令牌、凭据、账号
- 真实绝对路径（盘符、用户名、内部目录名）
- 真实供应商名、模型名、网关域名、内网地址与端口
- 角色卡的正文内容、世界书条目、立绘素材
- 聊天记录、用户数据、日志原文
- 验收用的真实样本卡（只提交**合成**样本，或只提交用例编号与观测）
- `.env` / `*.key` / `*.pem` / 本地数据目录

## 环境

- 依赖保持为零（mock 与契约不需要第三方包）
