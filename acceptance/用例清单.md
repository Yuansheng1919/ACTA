# 验收用例清单（按批次）

> 用例编号沿用评审回执。**样本不公开**：本仓库只放用例定义与观测口径，真实样本私下交付。

## 第一批 · 现在就能跑（假宿主，零外部依赖）

| 编号 | 输入 / 故障 | 唯一可接受的观测 |
|---|---|---|
| M0-01 鉴权与归属 | 缺 token；撤销后的 token；token B 读 A 的私有卡/会话；公网访问管理路由；合法 SDK 调主接口 | 未授权请求**上游次数为 0**；私有内容不可读；管理路由不可达；合法请求穿透真实反代；健康响应只给 `{"ok":true}` |
| M0-02 配额 | 剩 1 轮时并发 2 个作业；换 IP 重试；两 token 共用出口；重启 | 只放行一个，另一个 429；换 IP / 重启不恢复日额；共用出口仍分账；伪造转发头不改限速；重写尝试单独计数 |
| M0-03 闸门 | 假宿主只在最后一句加入拒绝标记；注入可修复长度错误；注入明确策略拒绝 | 抓包**看不到被拒草稿任何正文**；可修复错误最多 2 次生成；策略拒绝仅 1 次；最终失败时 `state_rev` 不变 |
| M0-04 隐私 | 在输入 / 生成内容 / 上游异常体各放唯一探针，触发一次成功一次失败 | 受检日志与错误回包**均无探针、凭据、原文**；同一 trace 能定位阶段与规则 |
| M1-01 规格与五段 | 年龄 17/18；非整数；未配置地点/时段；缺一段；纯空白；边界字数（恰好 / ±1） | 坏规格**调用上游 0 次**；18 岁合规进入生成；五段边界可复判；失败无可下载半成品 |
| M1-03 三轮结算 | 按下表固定事件走真实 HTTP + 真实 guard + 真实存储，只替换上游；另开同卡第二局 | 逐轮比对状态、版本、下一轮读回值；第二局保持初始值 |
| M1-04 重放与冲突 | 同一轮并发重发，随后同键异参；两轮竞争同一旧版本；提交后响应前断开 | 成功轮只结算一次；重试取回原结果且无新增调用；冲突为 409；重启后能区分已提交/未完成 |
| M1-05 守卫失效检测 | guard 临时替换为空操作；注入未知写路径 / 越界值 / 旧 guard 版本卡 | **空操作必使三轮测试失败**；非法候选不写盘不发正文；旧卡走绑定版本或报清晰不支持错误 |

### M1-03 三轮样例（合成配置值，预期表须手写，不得由被测 guard 生成）

| 轮次 | 起始状态 | 固定候选事件 | 提交后预期 | 核对点 |
|---|---|---|---|---|
| 1 | rev 0、地点甲、早 | 合法移动到乙 | rev 1、乙、早 | 第二轮实际装配读到乙 |
| 2 | rev 1、乙、早 | 合法进入晚时段 | rev 2、乙、晚 | 第三轮实际装配读到晚 |
| 3 | rev 2、乙、晚 | 合法移回甲 | rev 3、甲、晚 | 重启后读取；重放第 3 轮仍为 rev 3 |

三轮成功之外再提交一个**未配置地点**，预期仍为 `rev 3、甲、晚`，并记录被丢弃的候选事件编号。

| 环境与修订 | 用例编号 | 预期 / 实测 | 结果 | 证据定位 | 如失败，下一步 |
|---|---|---|---|---|---|
| commit、配置摘要、runner、客户端/SDK 版本 | M… | 状态值、字节数、上游次数或耗时 | 待测 / 通过 / 失败 / 此模式未承诺 | trace、卡哈希、脱敏差分或协议抓取 | 责任模块、复测条件 |
