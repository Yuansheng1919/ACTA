# 导入归一化规则

**多角色卡必须拒绝首次导入，要求调用方显式选一人。** 在选人前不写卡、不调模型。规则对预览和发布同时生效。导入仅接受数据；扩展登记仅含键、类型和个数。

## 输入与返回

`POST /v1/card/import` 使用业务 Bearer。JSON 对象放在 `file` 字段，二进制 PNG/ZIP 则放标准 base64。可带 `dry_run`、`select`、`overrides`（规格）、`texts`（五段逐字段人工改稿）、`external_world`。独立世界书通过 `base_revision` 关联自己的既有卡，成功生成新修订。ZIP 支持单层 Store/Deflate，一张主卡及附属世界书；多张候选、重复路径、越界、损坏 CRC 或嵌套包均拒绝。上限为上传 8 MiB、总展开 16 MiB、96 个成员。

| 阶段 | 裁决与可观察结果 |
|---|---|
| 容器与双块 | 校验 PNG 各块 CRC，两块均须能解析。新块 ccv3 优先，chara 单独存在时接受。逐顶层字段比较两个 payload 的深层值；不同则列出路径和新块优先裁决。损坏的新块拒绝，避免自动捡回旧人设。JSON 支持单卡及配对的 chara/ccv3 对象。 |
| 字段 | 新格式取 data，旧格式取平铺字段；嵌套与顶层冲突记录路径。保留姓名、五段、tags 和 creator_notes；旧 creatorcomment 映射到 creator_notes。系统提示、未采纳字段与扩展分别登记。原始脚本、删除的状态镜像及图片文本块不带入新卡。 |
| 多角色 | 结构化角色表或旧初始化树含多个角色时返回 422 `import.select_one` 和候选列表。未知选择返回 422。选择具独立字段的角色，仅采纳选中角色自己的五段；只有名字列表和共享正文时，另需逐项提交选中角色的五段稿。仅一位结构化角色才可进入 Engine。自由文本执行词表检查，其余语义由人抽查。 |
| 旧状态 | `[initvar]` 初始化块和行式状态镜像不参与执行或结算。非法时段“午”、未选角色路径均在报告中标识为未采纳。规格枚举列表过滤非法值并记录；无有效值就要求显式补齐。绝不把午猜成早或晚。当前 Engine 用选中规格首个合法地点和时段开局。 |
| 世界书 | 顺序为内嵌、ZIP 外部、显式外部。按非空 comment 合并，后源同注释覆盖；空注释独立保留。条目数组和稀疏键对象均接受。位置 0/1 映射为 before_char/after_char，深度不支持并记差异；不支持的位置、正则和选择性激活均不采纳。可用条目由 enabled、constant 或普通关键字决定是否进入装配。 |
| 发布 | 无年龄、非法枚举或任一段不达标时，预览返回差异和待补字段；提交返回 422 `import.review_required`。禁用词、模式、点名及显式未成年年龄在原始输入扫描阶段拒绝。人工修订重新过同一组闸门；首次成功才创建私有修订。 |

## d9e18d2 实测矩阵

五张 PNG 均与同名 JSON 对照，并验证各自的唯一探针。用项目方提供的 policy-sample.json 原样运行。

| 样本 | 文件级实测 |
|---|---|
| A 新规范 | 两块一致，五段与 JSON 对齐。 |
| B 旧规范 | 仅 chara，平铺字段通过，creatorcomment 映射通过。 |
| C 冲突 | 两块均被读取，采用新块姓名与正文，差异含旧块冲突字段。 |
| D 世界书 | 首次返回 422 和两个候选。显式选角色 A 后保留 1 条普通规则；非法午、另一角色、状态镜像、未知位置有独立差异记录。 |
| E 扩展 | 登记 regex、skin、script 各 1。原文件含 must not run；导入成功到达校验阶段，登记与采纳结果无脚本正文。 |

**文件解析 5/5。未补数据时原样发布 0/5。** 五张卡均缺年龄、地点集和时段集，五段也都低于这份策略各字段下限。显式补三项规格、逐段补至合规区间并对 D 选人后，真实 HTTP 发布 5/5，新增上游调用 0。输入保持原样；本地测试改稿只存在于请求。

M1-03 另按手写表用 A 原图、测试用甲/乙规则与显式成年规格跑真实 HTTP、宿主、guard、存储与重启。三轮每轮实际派发 1 次，状态为乙/早、乙/晚、甲/晚；第二局从 rev 0 开始，重放第 3 轮增加 0 次调用。N-1 至 N-7 逐项断言。N-7 用空 guard 运行完整三轮，实际每轮均为甲/早，与三个手写预期分别不符。N-6 以同 trace 的已派发待确认记录和宿主明确拒绝终态对账；供应商计费用量未知。

复跑：从仓库根执行 `node --test test/import*.test.mjs`。样本在单独检出的 main 时，把 `ACTA_ACCEPTANCE_DIR` 指向其 acceptance 目录。测试输出包含合成 session_id、轮次、版本、装配前态、期望/实测状态与调用数。完整私有词表和第三方客户端实机未验证。


N-7 收尾复验对正常与空 guard 使用同一套逐行断言。每行核对结算状态、下一次宿主实收前态及 guard_turn 痕迹；第 2 行另核对合法时段前进，第 3 行重启读回、重放结果与调用数。空 guard 的三行均须被正常验收断言拒绝，报告明确写“第一轮就偏离”。N-1 同时要求普通 JSON 错误、SSE 数据行 0 和草稿正文字节 0。
